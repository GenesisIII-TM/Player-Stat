# Genesis III — پورتال پرونده و آرشیو LOTM

## امکانات این نسخه

- کد آزمایشی `-%test%-` برای بازکردن نمونهٔ نمایشی استت‌ها؛ این کد **کلید امضاشدهٔ واقعی نیست** و تأیید رمزنگاری انجام نمی‌دهد.
- چارت شش‌ضلعیِ نسبی برای قدرت جسمی، استقامت، چابکی، معنویت، هوش و هوش رزمی.
- کارت ویژهٔ استعداد، و طراحی تازه برای هضم، لنگر، دانش و تجربه.
- جست‌وجو و فیلتر برای ۳۲ مسیر: ۲۲ مسیر استاندارد و ۱۰ مسیر غیرمعیارِ جدول نام‌گذاری ویکی.
- آرشیو ۱۹ مدخل گریت اولد وان: ۹ گروه زمینی + ۱۰ خدای بیرونی.
- `lore_database.json` داده‌ها را به شکل قابل‌ویرایش ارائه می‌کند. ۳۲۰ جایگاه سکانس در ۳۲ مسیر ثبت شده است؛ نام‌های مسیر Chaos Primogenitor از جدول سکانس‌های غیرمعیار صفحهٔ Sequence تکمیل شده‌اند.

## انتشار در GitHub Pages

1. فایل‌های این پوشه را در مخزن عمومی خود قرار بده.
2. از **Settings → Pages**، گزینهٔ انتشار از branch و شاخهٔ `main` / پوشهٔ `/root` را انتخاب کن.
3. بخش آرشیو مسیرها/گریت اولد وان‌ها بلافاصله قابل مشاهده است. نمادها از نشانی فایل‌های ویکی بارگذاری می‌شوند؛ برای بارگذاری تصویرهای نماد باید بازدیدکننده اینترنت داشته باشد.

## کد تست

در کادر اصلی دقیقاً `-%test%-` را وارد کن. نمونهٔ ساختگی باز می‌شود تا چارت و کارت‌ها را ببینی. این کد برای آزمون ظاهر است و **نباید** به عنوان امنیت یا تأیید یک پروندهٔ واقعی تلقی شود.

## کلیدهای واقعی LOTM1

برای ساخت کلید واقعی از موتور بات:

```bash
pip install -r requirements.txt
python stat_engine.py --init-keys
```

کلید خصوصی `keys/stat_private.pem` فقط باید روی سرور بات باقی بماند. کلید عمومی باید در متغیر `BUILTIN_PUBLIC_KEY_PEM` داخل `index.html` وارد شود تا تأیید کلیدهای کاربران کار کند. کلید خصوصی را هرگز در مخزن یا سایت قرار نده.

## آرشیو ویکی و حدود داده

`lore_database.json` شامل نام انگلیسی و نام فارسی نمایشیِ سکانس‌ها، گروه مسیرها، مسیر منبع و نام فایل نماد است. نام‌های سکانس از فهرست ویکی ثبت شده‌اند؛ نام سکانس‌هایی که در ویکی قابل تأیید نبودند، با `known: false` و متن «نام در ویکی ثبت نشده» مشخص شده‌اند و حدس زده نشده‌اند. این موضوع مخصوصاً برای سکانس‌های ۷ تا ۱ مسیر Chaos Primogenitor است. همچنین برای Sublunary Eye در فهرست رسمی نمادها تصویر مستقلی پیدا نشد و سایت نشان هندسی جایگزین نشان می‌دهد.

تصاویر نماد به کمک `Special:FilePath` از ویکی بارگذاری می‌شوند و به‌صورت فایل محلی دانلود/ذخیره نشده‌اند؛ محیط ساخت امکان اتصال مستقیم برای کپی‌کردن فایل‌های تصویری را نداشت. اگر نسخهٔ کاملاً مستقل و آفلاین لازم است، باید فایل‌های تصویری با دسترسی شبکه دانلود و در پوشهٔ assets قرار داده شوند و URLها به مسیر محلی تغییر کنند.

## تغییرات نسخه‌ی اصلاح‌شده
- بخش اطلس مسیرها از رابط بازیکن حذف شده است.
- با ورود کد آزمایشی `-%test%-`، پرونده‌ی نمونه باز می‌شود.
- اگر شهر بازیکن تینگن باشد، نشانگر قرمز روی نقشه‌ی تینگن نمایش داده می‌شود.
- در نبود مختصات، نشانگر با برچسب «موقعیت تقریبی» نمایش داده می‌شود. برای مختصات دقیق، داده‌ی `location` باید `map_x` و `map_y` نرمال‌شده بین 0 و 1 داشته باشد.
- نمادهای مسیر که در این نسخه به‌صورت تصویر قابل‌دسترسی از ویکی قابل دریافت نبودند، به فایل‌های محلی تبدیل نشده‌اند؛ سایت به‌صورت مستقل از این نمادها اجرا می‌شود.
